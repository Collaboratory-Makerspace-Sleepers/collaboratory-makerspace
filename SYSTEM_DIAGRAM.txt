┌────────────────────────────────────────────────────────────────────────────────┐
│                        API CALL SEQUENCES                                      │
└────────────────────────────────────────────────────────────────────────────────┘

ADMIN SETUP SEQUENCE:
═════════════════════

POST /api/v1/admin/hardware/unregistered-cards/{id}/assign-email
  ├─ Input: { "email": "testuser@makerspace.local" }
  └─ Status: PENDING → ASSIGNED

POST /api/v1/admin/hardware/unregistered-cards/{id}/assign-role
  ├─ Input: { "role": "MEMBER" }
  └─ Status: ASSIGNED → ROLE_ASSIGNED

POST /api/v1/admin/hardware/unregistered-cards/{id}/send-otp
  ├─ Generates: 123456
  ├─ Sends email to: testuser@makerspace.local
  └─ Status: ROLE_ASSIGNED → VERIFIED


USER LOGIN SEQUENCE:
════════════════════

GET /api/v1/auth/card/check-by-uid?uid=85F181D4
  ├─ Response: { "found": true, "email": "testuser@makerspace.local", ... }
  └─ Triggers OTP form display

POST /api/v1/auth/card/verify-otp
  ├─ Input: { "email": "testuser@makerspace.local", "otp": "123456" }
  ├─ Response: { "token": "eyJhbGc..." }
  └─ Stores JWT in browser

POST /api/v1/auth/card/activate
  ├─ Header: Authorization: Bearer eyJhbGc...
  ├─ Response: { "success": true, "role": "MEMBER" }
  └─ Redirects to /dashboard


┌────────────────────────────────────────────────────────────────────────────────┐
│                       ERROR SCENARIOS                                          │
└────────────────────────────────────────────────────────────────────────────────┘

Card not found:
  Status 404 → "Card not found - Contact admin for registration"

Card found but not assigned:
  Status 404 → "Card pending admin assignment"

OTP not found:
  Status 404 → "Invalid one-time code"

OTP expired:
  Status 400 → "Code expired - Request new code from admin"

Wrong email for OTP:
  Status 401 → "Code does not match registered email"

JWT invalid/expired:
  Status 401 → "Session expired - Sign in again"


┌────────────────────────────────────────────────────────────────────────────────┐
│                      SECURITY FEATURES                                         │
└────────────────────────────────────────────────────────────────────────────────┘

OTP SECURITY:
  • Random 6-digit codes (not sequential)
  • 1-hour expiration
  • Single-use only
  • Email verification required
  • Cannot be reused after verification

JWT SECURITY:
  • Issued after OTP verification only
  • Required for card activation
  • Standard JWT format
  • Signed with secret key

EMAIL SECURITY:
  • Admin cannot bypass email verification
  • OTP sent only to assigned email
  • Email ownership proven via OTP entry
  • Only registered email can activate card

ROLE SECURITY:
  • Dashboard content by role
  • Admin endpoints protected
  • User cannot change their role
  • Role verified on every request
